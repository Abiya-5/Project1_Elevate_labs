# HR Analytics – Employee Attrition Prediction

### Project Overview

This project focuses on analyzing employee attrition using data analytics, machine learning, SHAP explainability, and Power BI.

The system analyzes employee-related factors such as age, department, business travel, distance from home, education, education field, and daily rate to identify patterns associated with employee attrition.

A Machine Learning model is developed to predict employee attrition, while SHAP is used to explain the factors influencing the model predictions. An interactive Power BI dashboard is created to visualize the employee attrition patterns.

---

##  Objectives

- Analyze employee attrition patterns.
- Identify factors associated with employee attrition.
- Perform exploratory data analysis using Python.
- Develop a Machine Learning model for attrition prediction.
- Evaluate the performance of the model.
- Use SHAP for model explainability.
- Create an interactive Power BI dashboard.
- Provide data-driven insights that can support HR decision-making.

---

## Dataset

The project uses the `HR-Employee-Attrition.csv` dataset.

### Dataset Information

- Number of records: 1,470
- Number of attributes: 10

### Main Features

- Age
- Attrition
- BusinessTravel
- DailyRate
- Department
- DistanceFromHome
- Education
- EducationField
- EmployeeCount
- EmployeeNumber

### Target Variable

`Attrition`

- `0` – Employee did not leave
- `1` – Employee left
